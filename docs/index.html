¿Por qué GoKit?

Diseñado para desarrolladores que valoran la seguridad y la productividad.

API Dual: Rápido vs Configurado

Comienza con una línea de código usando nuestras funciones globales para prototipado rápido. Cuando estés listo para producción, cambia a constructores configurables sin reescribir tu lógica.

  • Rápido: crypto.HashPassword("pwd")
  • Configurable: crypto.NewHasher(customConfig)

Seguridad por Defecto

No necesitas ser un experto en criptografía. GoKit elige los parámetros más seguros por defecto (Argon2id, AES-256-GCM, Nonces únicos) para proteger tus datos desde el día uno.
